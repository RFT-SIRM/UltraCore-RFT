# Glossary

## RFT
Reality Fractal Theory — a research framework that treats code, mathematics, physics, economics, and distributed systems as a unified temporal topology.

## SIRM
Stable Invariant Rift Model — the invariant-preserving runtime design that governs UltraCore Rift.

## UltraCore Rift
A research architecture applying RFT principles to deterministic execution and Solana runtime models.

## Global Field
A scalar field concept used to model uniform state shifts across participants in a deterministic economic system.

## Invariant
A mathematical identity or condition that must hold throughout runtime state transitions.

## Field Trials
Operational review and validation of the repository concepts and external implementation under realistic conditions.

## Launch Readiness
The state in which documentation, architecture, and implementation are aligned for technical review and practical evaluation.
