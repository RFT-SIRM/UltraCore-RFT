# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| main    | Active research and development |

## Reporting a Vulnerability

Do not open a public issue for security vulnerabilities.

Report privately via GitHub Security Advisories or email the project maintainer.

Include:
- Clear description of the vulnerability
- Steps to reproduce (if applicable)
- Affected repository and file(s)
- Potential impact assessment

We aim to respond within 72 hours.

## Scope

This policy applies to:
- [Rift-Network](https://github.com/RFT-SIRM/Rift-Network)
- [Rift-L1-Blockchain](https://github.com/RFT-SIRM/Rift-L1-Blockchain)
